# 杨柳岸申论理念课 · 方法笔记（A批：理念课1-4）

> 总纲：**欲学其事，先明其理。** 理念课不讲技巧，讲申论的底层逻辑——树立正确的"申论观"，才能以不变应万变，打破申论玄学的枷锁。

---

## 理念课1：申论的本质——申论到底是什么？

### 核心观点
- **申论是模拟机关日常工作的一门考试。** 很多人知其然不知其所以然，要弄懂它"如何模拟"。
- 申论材料在选题上有特殊性：从不选文学性、抒情性、企业成功学文章，一切选题关乎社会主义建设、国家发展、政府工作；即使谈个人/企业成长，也是在政策支持下发展起来的。
- 反对"对策邪教"：认为申论无非"找问题抄对策"的考生，出考场觉得点踩全了、一出分只有50多，然后给申论贴玄学标签——这是认知不足导致的稀里糊涂。
- "稀里糊涂拿高分"是运气，运气不是人人都有的；要明明白白上岸，稳定拿高分。

### 操作方法（理解申论的四个对应关系）
1. 先自问：申论是什么？材料是什么？题干是什么？答案是什么？——带着问题听课，主动思考而非被动接受（"思考不只是一种能力，更是一种习惯"）。
2. 读材料开篇先识别**政策背景**：开篇交代的大政方针，决定整篇材料的主题方向（如见"林海苍翠"→必考生态建设主题→必关联经济发展）。
3. 建立机关工作的类比框架：
   - **申论材料 = 大政方针在各地区的具体实践**（可记在本子上反复揣摩）
   - **申论题干 = 领导的指示与要求**
   - **申论答案 = 最终呈现的工作成果**
   - 解题过程 = 领导让你写工作总结：牢记领导指示（题干）＋回忆工作过程（材料）→整理成文。
4. 公务员工作追溯到根上都是基于国家大政方针开展的（"上有政策，下有对策"），理解这一点才能理解材料为什么这么写。

### 原创术语及定义
- **对策邪教**：把申论理解为"找问题、抄对策"，只凭感觉踩点、不问材料本意的错误流派。
- **申论观**：对申论这门学科全面、正确的底层认知，是学好申论的前提。

### 真题/案例
- A市生态材料：开篇绿水青山背景→引出"生态产品价值实现机制试点"政策→预判后文必讲A市如何把"两山论"落地为实践——印证"材料=大政方针的具体实践"。

## 理念课2：申论真正考查的是什么？（上）——能力

### 核心观点
- 申论考察两个方面：**能力**（大纲白纸黑字的能力）＋**积累**（政策与规范表达）。两者彼此独立、相辅相成。
- 大纲中各项能力分级：综合分析、贯彻执行、依法办事、公共服务等能力只有**特定题型/材料**才考；**阅读理解能力和文字表达能力是贯穿始终的最底层能力**。
- **申论是主观形式的客观题**：答题形式主观（自己写），但答案客观——一切答案源于材料，一切要求都在题干中。申论答案绝不是课下背出来的，更不是主观想象出来的。
- 最反对的学法：**"标签式阅读"**——给材料贴"问题""对策"标签后直接拼答案，属于零阅读零理解；把申论大纲和命题人都当笑话。
- **以理解材料为根本，技巧方法都是辅助性的作用**，不能本末倒置。行测可以靠技巧秒杀，申论必须回归本质、靠理解。
- "申论拼到最后，其实就是对理解能力的考察。"（上岸学员语，老师高度认可）

### 操作方法
1. 判断自己是否走入歧途：回想做题时注意力是否都放在"凭感觉找点"上，有没有真正尝试理解材料内容。
2. 读到"对策"先验证再使用：必须结合上下文确认它是否真的解决了前文问题，再决定能否作为要点。
3. 用行测言语理解的思路检验自己：把申论段落当言语题读一遍——若言语能做对而申论做不对，说明不是读不懂，而是做题思维有问题。
4. 答案从材料中来的三条路径：直接抄 / 概括总结 / 分析推导。

### 原创术语及定义
- **标签式阅读**：只给材料贴标签（问题/对策）、归类找点，不追求理解含义内涵的读法。
- **主观形式的客观题**：形式主观、答案客观，"不要你以为，而要作者以为"。

### 真题/案例
- 无人咖啡屋"联合审议"段：多数考生和机构把"联合审议"当对策，实际结合上下文看，它和滞后的审批标准一样**没有解决问题**——整段核心是引出第四句"新兴业态审批难"这一问题；把联合审议当对策，与作者本意完全相反。

## 理念课3：申论真正考察的是什么（下）＋大纲解读——积累

### 核心观点
- **积累不是背好词好句、背人物案例**，而是对习思想、大政方针、政府工作的了解程度。
- 积累的作用有二：①帮助读懂材料（答案虽在材料里，但对政策完全不了解时材料会看不懂）；②让答案表达更规范。
- 裸考生能拿还不错的分数，是因为答案都源于材料——积累的小瑕疵对分数影响不大；但有积累则"扫一眼就能写出来"。
- 大纲中"用习思想解决问题的能力"一句并非虚话或官僚话，它**映射着命题思路和申论本质**，对应的就是"积累"这一方面；看不懂只因太笼统，需要做题经验回过头才能读出精髓。
- 申论阶段掌握大政方针，对后续面试帮助非常大。

### 操作方法
1. 积累政策概念时问自己：它的核心内涵是什么，材料出现哪些完整证据时才适合用它命名？
2. 概括材料时可把政策概念当作候选小标题，但必须先由材料读出共同指向，并核验每个小点都受该概念统领。政策概念只能命名材料已经证明的关系，不能反向制造关系。
3. 系统课要**常听常新**：不同阶段回听同一套课，感触完全不同——纯小白阶段只能被动接受，刷题后再听"每句话都说到心坎上"。

### 原创术语及定义
- **积累**：对习思想（=大政方针，如两山论、三产融合）、政府工作、规范性表达的掌握程度，本质是一种**政府思维**。
- **习思想＝大政方针**：大纲用语的大白话解读。

### 真题/案例
- 紫菜案例："建紫菜育苗基地（一产）＋打造精加工产业园（二产）＋发展特色渔村旅游（三产）"，看似三个散点，实则一个大点——小标题应写"**实现三产融合发展**"；不懂政策的人理解能力再强也想不到这一层。

## 理念课4：申论的复习规划——申论学习的四个阶段

### 核心观点
- 这套四阶段是老师认为较科学的一种理想方案，**并非准则**。每个人时间和基础不同，应理解每一步的目的后按实际情况调整。
- 申论学习分两大方面：**对真题的研究**（答题技巧、命题规律）＋**对时政的了解**（积累）。措辞上"研究"vs"了解"即孰轻孰重：**真题为主，时政为辅**。
- 时政只是如虎添翼，起不到雪中送炭的作用——因为申论有材料，答案基本都在材料里。
- **时政不能代替材料，但材料包含了时政**：时政是高度凝练的，申论材料有背景、观点、案例、评价穿插，综合性强、谋篇布局完全不同，两者阅读方式不同——平时要练的重点就是申论材料本身。
- **申论刷题质量大于数量**，与行测（量变引起质变、刷三万题）完全不同：申论的提高"有时候真的就是一瞬间的事儿"（申论开悟说）。
- "学其上者得其中，学其中者得其下，学其下者无所得"——平时对自己要求高一点，考场上使出八成功力上岸足矣。
- "你获取知识的时候，你并没有真正的掌握知识；你体会到知识的时候，你才真正的掌握了知识。"（王阳明知行合一：理论指导实践，实践检验和深化理论）
- 一天一套卷的节奏注定是标签化、浅表化阅读——"勤能补拙"在申论上没那么适用。

### 操作方法（四阶段规划）
1. **第一阶段·理论学习**：跟系统课快速过一遍，建立基础概念、有个大概印象即可，不需花太多精力——脱离真题的理论没有意义，真正的掌握在第三阶段。
2. **第二阶段·刷题**："**以真题为导向，边学边积累，质量大于数量**"：
   - 每天4-5小时给申论的话：难题一天一道，简单题一天两道；
   - 每道题**多写多改**——反复修改答案就是进一步分析材料、吃透材料的过程；
   - 时政积累用碎片时间（地铁、睡前），不要拿整个下午读时政挤占真题时间。
3. **第三阶段·理论回顾**：开倍速二刷系统课或刷题中随时回顾——第二遍理论学习比第一遍更重要，"当你头皮发麻的时候，系统课才真正完成闭环"。
4. **第四阶段·针对性练习**：考前针对所报岗位做近三五年真题：①熟悉考情特色（北京/广东材料多、广东考策论文、国考整体性强且大作文抽象、江苏爱案例型材料、执法卷侧重依法治国）；②作为考前全真模拟感受节奏。
5. 附：判断理解能力是否提升的小技巧——**记录行测言语理解的正确率**作为衡量标准。

### 原创术语及定义
- **以真题为导向，边学边积累**：不单独开政策课，在分析真题材料的过程中完成对时政的积累——更高效，对政策理解也更深刻。
- **质量大于数量**：一篇材料只有真正读懂搞透，才能摸索命题规律、举一反三。

### 真题/案例
- 反面典型：一位刷了50套题（一天一套、每天下午两点准时模拟）的同学，一对一批改后发现仍是小白水平——课程中多个反例以其为原型。
- 滑雪学单板：先怀疑"重心前压"理论，摔了两个小时后回看教学视频才有全新认识——印证"不同阶段学理论感触完全不同"。
