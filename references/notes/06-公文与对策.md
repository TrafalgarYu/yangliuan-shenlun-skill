# 06 公文题与主观对策题 · 方法笔记

> 来源：杨柳岸申论基础理论课（基础理论8：公文题；基础理论11：主观对策题）
> 性质：方法提炼，供个人学习使用

---

## 一、公文题基础理论

### 1. 题型定位：申论最关键的题型

- **考得多、分值大**：一套卷有时出现三道公文题，分值通常较大。
- **分差大**：不像概括题大家写得差不多，公文题"三六九等一目了然"，是最能体现水平、拉开分差的题型。
- **判断标志**：题干出现"撰写一份提纲""起草一份发言稿"等表述。
  - "对此提出建议" = 对策题（列观点即可，不需成文）
  - "起草一份建议书" = 公文题（须整合成完整文书）
- **成文是公文题区别于其他小题的最大特征**。概括、分析、对策三种小题只是观点表述，无格式要求；公文须成文，因此额外多了格式、内容结构、语言三方面要求。

### 2. 基本常识：申论考的不是正式公文

- 严格意义的公文是单位公文系统内流转的 15 个文种（中办指定），格式要求极苛刻（字体、字号、国标），**申论基本不考**。
- 申论考的是倡议书、建议书、讲话稿、提纲、短评、公开信、编者按、工作总结等——属**事务文书、应用写作**范畴。
- 应用写作 = 有功能属性、发布后要产生社会作用的写作（公开信用于回应说明、倡议书用于倡导引导、短评用于简要评价）。
- 因此形式要求不高，**关键在内容**。

### 3. 成文带来的三个额外要求

**（1）格式**：标题、称呼、落款。不同文种要求不同（有的不写称呼落款、标题有自拟与格式化之分、有的干脆不写标题），需要掌握常见文种的具体要求。

**（2）内容结构**：整篇公文的框架层次（先写什么、再写什么）。三种最常见结构：

| 结构类型 | 说明 | 段落划分 |
|---|---|---|
| 多要素并列 | 某道建议书材料的示例为意义 + 问题 + 措施，不代表所有建议书 | 一个要素一段 |
| 单要素总分 | 全文讲同一要素（如通篇工作思路），开头总述（宏观）+ 正文展开（中观、微观） | 开头一段、正文一段 |
| 多要素总分 | 多要素并列 + 一个总结性开头 | 开头 + 各要素分段 |

> **核心观点：内容结构是解题的结果，不是过程。** 是通过对材料的梳理、根据材料提供的内容安排出来的，而不是先定结构再把材料打碎往里填。顺序不能颠倒。

**（3）语言**：
- 流畅性：要成文，起码读得通、读得顺，比其他小题要求高。
- 创新性：通过修辞、对仗增强可读性，**只体现在大标题和小标题上**，正文完全不需要加工，属酌情加分项。
- **老师明确不建议在这方面努力**："先考虑写的对不对，再考虑写的好不好"；创新表述依赖灵感和经验，强求不得；"步子迈大了，还容易劈叉"，能"准确、规范、简洁、明了"完全够用——这对多数考生已经是高标准。

### 4. 核心解题方法：文种特性 × 材料梳理

学好公文题就两点，**相结合就是答案**：

1. **掌握文种特性**：知道倡议书是啥、发挥什么作用；知道短评是啥、要注意什么。文种特性 = 这份公文的功能性。
2. **梳理好材料**：顺着材料三观梳理内容要点（鸡蛋关系：材料和题干互相配套），材料梳理清晰，公文的内容结构自然确定。

**操作步骤（以短评为例）**：
1. 先明确文种特性：短评的关键词在"评"，评即观点——不能只是事迹概括，必须发表观点做评价（题干一定会有"观点鲜明"之类要求）。
2. 梳理材料：博士城管材料围绕人物讲了四件事 → 这四件事就是材料的中观层次。
3. 确定内容结构：麻雀虽小五脏俱全——开头写对人物的整体总评（对应宏观），正文对每件事分别评价并在背后概括事迹（对应中观），即单要素总分。
4. 补上格式（标题），即完成作答；能力高的可再加工标题的文学性。

### 5. 最大误区：背固定框架（正反结合）

**反对的学法**：不去了解文种特性、不去梳理材料，而是给每种公文背固定框架（如"倡议书 = 意义 + 措施""建议书 = 背景 + 对策"），考场上判断文种、直接套用。

**核心论断——分清变与不变**：
- **不变的是文种特性**：倡议书一定要起倡导作用、结尾一定有倡导引导的语言；短评是评论性文体，一定要有观点；建议书一定要提建议。
- **变的是内容结构**：材料给的不一样，每篇公文的内容安排一定随材料变化。
- **金句：群体可以反映个体，但个体很难代表群体。** 这篇倡议书开头交代背景，不代表所有倡议书都要交代背景。
- **日常掌握不变的东西，考场上应对变化的东西。** "没有认知的努力，就是白忙活"，甚至反作用——"你不背还好，一背反而完蛋了"。

**顺势而为 vs 逆天而行**：
- 势 = 命题人给你铺的路。顺着材料、顺着题干要求整理答案，就是顺势而为。
- 课下自造框架，考场上不顾材料脉络，把材料打碎往框架里套，就是逆天而行，一定滋生问题。
- 背框架的根源是**惰性思维**：想在考前把一切准备好（如整 20 个文种框架全背下来），考场上省事。
- **金句：你在考场上越省事儿，越不去分析材料，你反而越容易出事儿。**

### 6. 文种积累与临场分析（兜底策略）

- 事务文书可分出上百种，**永远考不完也讲不完**，考场上永远会出现没写过甚至没听过的文种——要有风险意识；但风险伴随机会：大家都陌生，你能处理就脱颖而出。
- 应对两层：
  1. 刷题过程中自己持续积累文种特性和格式要求。
  2. **更重要：学会对文种特性和格式要求做现场分析判断**。大多数事务文书比较生活化，可通过名称、适用场景、功能属性做常识判断。
- **案例（作品征集启事）**：没写过也能推——征集启事就是办比赛、发布公告让人报名参与 → 要让人知道谁办的 → 有落款；要办比赛 → 须写清参与方式、作品要求、活动时间，否则不符合"可行性强、要素齐全"的要求。
- 原理：文种特性和格式要求都在为公文的功能性、适用场景服务，结合题目要求和应用场景即可"写个八九不离十"。
- **金句：创新就是当下公考命题的大趋势**——只能靠经验解题、不能靠能力解题的人，在申论和面试学习中一定会很痛苦。无论申论还是面试，永远做好面对新题的准备。

### 7. 公文题完整作答流程

1. 审题：题干有"撰写/起草一份××"→ 判定公文题，明确文种。
2. 调取或临场分析该文种的特性（它要发挥什么功能）及格式要求。
3. 梳理材料：建立宏观—中观—微观三观，理清层次。
4. 由材料梳理**得出**内容结构（结果，不是先定框架）。
5. 按结构组织内容，补上标题、称呼、落款等格式。
6. 语言保流畅通顺；有余力且有能力，再对大小标题做创新性加工（非必需）。

## 二、主观对策题基础理论

### 1. 题型定位：为什么叫"主观"对策题

- **"提出" vs "概括"**：概括是对材料重点内容的提炼；提出是需要你自己去提的——无法从材料中直接获取对策（或全部对策），要调动平时积累和工作生活经验。这是"主观"二字的由来。
- 是**申论难度最大的题型**：概括、分析、公文题的基础手法都是归纳概括、答案源于材料梳理；对策题不能靠归纳概括完成作答。
- 难度大 = 机会：地位类似行测的数量关系，大家普遍答得差，攻克它就是**弯道超车**的机会，可能成为"高分中的高分"。
- 命题形式：多数是"梳理问题 + 提出建议"两部分（呼应国考大纲——**问题一定来源于材料，靠概括把握；措施需要自己提出**）。个别省考只让提建议，不要答出惯性，认真审题。
- 材料特点：**以问题的描述为主**，一千多字几乎通篇是问题。

### 2. 两个基础困惑的解答

**（1）答案结构**：题目若明确要求"所提建议与问题一一对应"，就按问题一+措施一、问题二+措施二……写；没要求其实无所谓。**干脆统一**：无论有无要求都按一一对应的结构作答——好处是能体现措施的针对性。（从没见过要求把问题和措施分开写的题。）

**（2）内容占比**：**一定以对策为主**。对策题的命题初衷是考解决问题的能力；问题的梳理靠归纳概括能力，已由前面的概括题考过。经验上问题 : 措施 ≈ **1:3 到 1:4**（400 字题：问题约 80–100 字，措施约 300–320 字）。
> 注意：占比是**结果，不是解题方式**——问题概括准、措施提得可行，自然就是这个比例，不要人为控制字数、影响分析判断。

### 3. 核心方法一：问题要写出概括性（从中观概括，不从微观抄）

这是对策题关于问题梳理最核心的理论：

- **要从中观层面去概括问题，而不是从微观层面去抄问题。**
- **材料的中观层次决定了问题的数量和每一个问题的重心**：中观切成三部分就有三个问题，切成四部分就有四个问题。经验上整个梳理下来是**三到五个问题，每个问题一句话**即可，不需要再写小标题（问题本身就是从千字浓缩成百字，已极具概括性）。

**操作步骤（以 2021 年人行道真题为例，可当母题）**：
1. 材料共 1500 字，近 1000 字都在讲问题；总分总结构，正文按场景划分出**三个中观层次**：固定设施占道（树木、井盖、电表箱）→ 施工工地影响 → 秩序问题（车辆乱停、摆摊、人车混行、车速快）。
2. **乱中求序**：依据材料合理性意识，问题罗列看似散乱，背后一定有框架、有逻辑——申论材料里的采访报道是作者设计出来的，不能当真实碎片化报道看。
   - 生活化类比：夸张三要写成正式文章也必有逻辑——先夸外在（五官→体型）再夸内在（性格→内涵）；外在/内在就是中观，五官、体型是微观。
3. **抓线索**：结尾总结段藏着很隐蔽的总结性排比"统筹**建设与管理**"——它是对全文的呼应（本题巧妙在每个层次内部都体现建设、管理两方面），顺着这两个角度梳理散乱问题。
   - **注意**：排比词只是内在逻辑的提示，**不能直接拿"建设""管理"当答案表述**，必须结合材料具体问题写出"建设方面的问题体现在哪、管理方面体现在哪"。
4. 概括成句：如"人行道功能区域规划不科学，交通秩序混乱，存在占道经营问题"——1000 字浓缩为 30 字。

**关于踩点得分的正确理解**：
- 问题部分仍是踩点得分，但**点不是微观的碎点，而是中观层面的逻辑框架点**：3 个层次 ×（建设、管理）2 个角度 = 6 个点。
- **写出概括性容易，概括得准确不容易**：既需要对中观的把握能力（切割得准），又需要对微观的理解能力（理解得准），才能"概括到命题人的心里"。
- 从微观抄问题的两个恶果：① 问题十几条，光问题字数就不够，"还要管大作文那边再借 200 个格子"；② 对策没法提——树木绊倒人就挪树、井盖不平就铺井盖、工期缓慢就加快进度，"每一条都是废话"。
- **金句：材料的中观层次决定了问题的数量和重心，这就是答案条理性的体现；结合微观具体表述确定最终写法，这就是答案全面准确性的体现。**

### 4. 措施的两项基本要求

- **针对性**：措施一定是为解决**材料中反映出的问题**而提的。反例：哪怕是土木专业出身的"好建议"，针对的是相关工作而不是材料反映的问题，也不行。所以把问题梳理准确是提措施的前提。
- **可行性**，分两方面：
  1. 实际可操作、不假大空、符合常理；
  2. **符合政府工作的身份定位**（易被忽略）——申论是对相关工作的模拟、上岗能力测试，必须站在公共管理角度、以符合政府工作制度的方式解决问题。反例："找有关部门进行投诉"是老百姓/商户视角，身份定位搞错了。
- **措施不是传统意义上的踩点得分**：问题部分踩点得分，措施不唯一，只要符合针对性、可行性两项要求即可。

### 5. 核心方法二：对策怎么提——成因分析两步法

**反对的做法**："根据问题反推对策"——直接从表面问题推措施，分不清措施和效果，把想达到的效果当措施写，是"完全脱离现实的纸上谈兵"（树木挡道就移树：谁来移？怎么移？）。

**两步法**：

**第一步：分析问题成因，确定措施方向。**
- 透过现象看本质，**多问两个为什么**：为什么树木会跑到盲道上？→ 规划初期交通部门与市政部门各自为政、没有统筹协调 → 措施方向就是**统筹协调**。
- 问几个合适？**一般问一到两个为什么就行**。深挖是无底洞（规划没协调→为什么没协调→体制机制→上级不重视→……"殊途同归，问到最后就是盘古就不该开天辟地"），**挖得太深，离问题就远了**。
- 命题人常在结尾总结性观点里藏方向提示（如"统筹建设与管理"）——注意**方向 ≠ 措施本身**，方向是解题的大方向，还要写具体。

**第二步：结合积累把措施写具体。**
- 围绕方向，结合常识性判断、生活工作经验、刷题和阅读积累，把措施写出针对性、可行性。
- 人行道真题示范：交通、市政、绿化、通信等部门**成立联合整治小组**，明确各自职责，对存在问题的设施统一排查整改；加强日常维护管理；城建部门合理规划、完善建设标准；完善考评机制、引导群众参与监督，倒逼落实主体责任。
- 关键在"涉及不同部门的问题就要做统筹协调"——但这是**这道题的特色**（材料切三个场景、每个问题都涉及多主体，且结尾有提示），不是对策题的共性，切勿当成万能套路。

### 6. 为什么不给"拿来就用"的模板

- 有人问"能不能讲点拿来就能用的"：老师能讲（如"疏堵结合、放管结合"，"事前宣传、事中监督、事后处罚"任何事都能套），**但这么讲会害人**——你会摒弃对问题本身的分析与思考，直接掉进模板化、套路化的陷阱。
- **金句：这种拿来就用的东西，确实能让你把答案写得满满当当、写得轻松愉快，但是它不会管你的死活。**
- 题干为什么提"针对性"？**如果能够用相同的思路去解决完全不同的问题，那这个世界上就不存在问题了。**
- 课程里能拿来就用的（总结性排比、段落划分、连词、非常规要求）属于**命题规律**；而对策题的措施**没有规律可循**——材料不同、问题不同、成因不同，解决方式自然不同。
- "你觉得在考场下把问题都解决了，反而意味着你在考场上会面临更大的问题。"反模板反套路是当下命题趋势，不要趋之若鹜。
- 正确姿势：顺着"先分析成因定方向、再结合积累写具体"这个思路去思考、分析，在过程中提高解决问题的能力——从完全做不到，慢慢变得能一定程度做到，面对这种普遍拉胯的题型就够用了；走捷径背万能公式的人，"将永远做不到"。

### 7. 主观对策题完整作答流程

1. 审题：确认"梳理问题 + 提出建议"的命题形式（有的题只要求提建议）。
2. 若题干要求写问题，梳理材料中观层次以确定问题数量与重心；3—5 个只是老师的常见做题经验，实际由题干和材料决定。再用微观内容把每个问题写准。
3. 对每个问题多问一两个为什么，分析成因 → 确定措施方向。
4. 结合本题成因、可用主体与实际条件，把措施写到可执行，满足针对性 + 可行性（含政府身份定位）。方向不等于措施，不强制出现部门、机制等固定构件。
5. 按问题一+措施一……一一对应结构成文；问题:措施自然形成约 1:3–1:4。

**打好对策题的三字诀：问题上概括准、措施上会分析、多积累。**

## 三、两题型共性：顺势而为的方法论

| 维度 | 公文题 | 主观对策题 |
|---|---|---|
| 答案来源 | 材料梳理 + 文种特性 | 问题源于材料概括；措施靠成因分析推导 + 积累 |
| 共同敌人 | 背固定框架（逆天而行） | 背万能模板（疏堵结合、事前事中事后） |
| 共同心法 | 顺着命题人铺的路走；掌握不变的规律，考场应对变化的内容 | 同左 |
| 结果观 | 内容结构是结果不是过程 | 内容占比（1:3–1:4）是结果不是方式 |

**贯穿两课的金句**：
- "你在考场上越省事儿，你越不去分析材料，你反而越容易出事儿。"
- "没有认知的努力，就是白忙活。"
- "群体可以反映个体，但个体很难代表群体。"
- "拿来就用的东西……它不会管你的死活。"
- "如果能够用相同的思路去解决完全不同的问题，那这个世界上就不存在问题了。"
- 学会听课 = 学会读材料：听例子要听懂背后的理论，"考场不考同样的题目，申论的学习一定是通过对典型题的研究，去解决一类题目。"
