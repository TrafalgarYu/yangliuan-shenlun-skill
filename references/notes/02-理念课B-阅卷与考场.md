## 一、理念课5：阅卷标准（上）——要点 + 语言

### 1. 核心观点

**主张：**
- 申论阅卷标准不是扁平的"踩点得分"，而是**立体的四维规则：要点、语言、逻辑、卷面**。只知踩点，对评分标准的认识就太片面。
- 踩点踩的不是某个关键词、字、句，而是**要点（观点）**。同一观点有多种表达（"发展观念变化 / 发展理念变化 / 生产观念变化 / 生产理念变化"四种说法都对），这是申论的主观性与灵活性——"主观形式的客观题"。
- 官方坚持人工阅卷，是因为人工阅卷在申论上有不可替代性；真实考场的踩点得分是相对灵活、科学的。

**反对：**
- 反对"杀错不可放过"式多写踩点（字数上限卡死，写无关内容必然挤掉关键内容）。
- 反对迷信网上的智能批改（机械死板，认知会被带偏，白花冤枉钱）。

### 2. 操作方法：语言三要求——准确、规范、简洁

**(1) 准确（基础）**
- 定义：无论用词如何，观点内涵必须与材料**同一**，不能是"近义"，更不能"偏离"。
- 自检技巧（老师自用）：答案 = 观点 + 展开。展开部分 80% 源于材料，很少写偏；**写偏的往往是前面的观点**。把观点部分与展开部分对比，前后不一致即为不准确。
  - 反例：观点写"生产方式变化"（行为层面），展开却解释"天经地义→自觉"（思想层面）→ 前后矛盾，必错。不用看材料，单看答案即可判断。
- "贴边但不准确"（如写"思想观念变化"，太笼统）→ **酌情给分**：值2分的点给1分或1.5分。分数小数的两个来源：多考官平均 + 酌情给分。所谓"压分"压的就是酌情给分——**答案写准了，压分压不到你头上**。
- 写不准的两个病根：
  - 输出端：词汇量有限，读懂了但词不达意；
  - 输入端（多数人）：材料压根没读懂或解读过于主观。
  - 金句：**"读懂材料是写准答案的前提。"** 纠结用词时，与其原地纠结，不如回头再看一眼材料。

**(2) 规范（关键）**
- 所谓"高级的答案"就是规范性表达——入职后所写材料都有官方属性，这是公务员工作性质的必然要求。**准确性是基础，规范性是关键，既要表又要里。**
- 反面案例：材料只讲"发展文化旅游"，考生联想到乡村振兴就写"以三产融合促乡村产业振兴"——看着高级，实则偏离材料原意，"只有表没有里"，绝对得不到分。外行看热闹，内行看门道。
- 规范词怎么积累：**不建议专门背规范词**（双刃剑，脱离语境易生搬硬套）。以真题为导向、在做题过程中结合材料语境积累，才能理解深刻、用得恰当。

**(3) 简洁**
- 申论字数要求特殊：除大作文外都是**设上限**（不少于→不超过），核心目的是考察"能否抓住材料重点"，本质仍是大纲要求的阅读理解能力。
- 拆成两条：
  - 内容上抓重点：典型结构"观点 + 例子"，例子只是解释说明观点，概括主要观点时**只写观点、不抄例子**；
  - 文风上简洁明了：观点也不能整句照抄，去掉修饰性内容、提取主干（"捞干的写"）。
- 自检：若字数不够用，说明要么写了无关内容，要么语言重复啰嗦（300字题写准写全要占280-290字）。

**(4) 进阶：创新性与文学性（酌情加分项）**
- 只针对**公文和大作文**（成文的题）；概括、分析、对策题纯考观点概括，无文学性要求。
- 必须建立在准确、规范、简洁的基本要求之上，**切勿本末倒置**——为追求对仗工整牺牲内涵，答案就"只有表没有里"。
- 理想状态是"既有面子又有里子"，但对99.9%的考生极难；**退而求其次：内涵（里子）正确优先，面子稍差没关系**。"没有阅卷人会喜欢徒有其表的答案。"

### 3. 原创术语及定义

| 术语 | 定义（保留原话） |
|---|---|
| **申论语言的和而不同**（引钟君老师） | 同一观点可有多种表达，内涵一致、用语准确即可得分，答案并不唯一 |
| **主观形式的客观题** | 申论作答形式主观，但踩点（观点）客观，决定了阅卷的灵活性与科学性 |
| **只有表没有里** | 用语看似规范高级，内涵却偏离材料原意的答案 |
| **酌情给分 / 酌情加分** | 贴边但不准确的用语给部分分；文学性、创新性带来的额外分 |

## 二、理念课6：阅卷标准（下）——逻辑 + 卷面

### 1. 核心观点：逻辑 = 要点之间的关系

- **逻辑**：通俗讲就是要点之间的关系，主要是**总分关系**和**并列关系**（偶尔因果关系，考得极少）。
- 金句：**"总分关系让答案有了层级，并列关系让答案有了次序。有层有次，答案便有了层次。"**
- 无逻辑的答案即使要点齐全、语言规范，也给人"一盘散沙"的感觉；用小标题把答案切割成块，才条理清晰。

### 2. 操作方法

**(1) 找逻辑（结合真题案例）**
1. 梳理材料行文：材料先抛出问题（"文化的生命在于用，在于融入群众生活"），紧跟着回答（发展文化旅游）→ 这就是全段核心观点；
2. 核心观点之后的展开内容（生态和文化旅游融合发展 = 理念思路；修建现代化文化景观汇聚人气 = 引流；数字化赋能提升游客体验 = 留客），逐一判断其功能；
3. 将展开的要点归到核心观点之下，形成**"一带三"的答案结构**：大哥（文化旅游）+ 三个小弟 → 大哥与小弟之间是总分关系，小弟之间是并列关系。

**(2) 卷面**
- 一句话标准：**"字写得好看不加分，但卷面不工整、乱涂乱改会扣分。"** 要求就四个字：工整清晰。
- 代价量化：卷面分占比不高，但每道题扣1分，一套卷就是四五分，70分变65分，太吃亏。
- 两条经验：
  1. **下笔前要三思**：卷面本质是意识问题，思路不清晰不要动笔；
  2. **下笔后能不改则不改**：除非重大失误，一两个错别字（多一横多一点）不要动——不涂改阅卷人未必发现，一涂改必影响卷面分。
  3. 尽量用楷体书写。

### 3. 本两课总结：四维标准与作答要求的对应关系

题干常见作答要求"**全面、准确、有条理**"正好对应前三项阅卷标准：
- 全面 = 要点齐全
- 准确 = 语言准确
- 有条理 = 逻辑正确
- （外加卷面整洁）

三者不独立，有传导关系：**要点齐全是逻辑正确的前提**（逻辑是要点之间的关系，少一个关键点如"一栋楼少一根承重墙"，整个答案垮掉）；**语言准确是要点齐全的前提**（点找到了但写偏了，要点分照样没了）。

### 4. 最重要论断（批改两三百份/年、成千上万学生的经验）

- 考生注意力普遍只在"点踩全没有"，很少有人检讨语言和逻辑——这是认知盲区。
- **大家在踩点上的差距没那么大，找的要点都差不多；小题最大的差距在逻辑性和语言上。**"你的视野、你的格局，决定了你发展的上限。"少一两个点扣不了多少分，但逻辑（答案结构）一垮，地基没打好，整个答案就垮掉了。
- 最关键的认知翻转：**"要点齐全、逻辑正确、语言准确，不是过程，不是我们追求的目标，这只是一个结果；审对题干、理清材料、读懂材料，这才是我们追求的目标。"** 材料搞定了，答案自然符合要求；脱离材料钻研答案，永远整不明白。学习重心要放在材料上，而不是答案上。

## 三、理念课7：阅卷制度与阅卷流程

### 1. 流程（老师渠道了解，各地大同小异）

**准备阶段：**
1. 考后阅卷人集中到封闭区域统一培训（保密规格极高，命题、阅卷甚至选在监狱，与外界完全断联）；
2. 命题人/专家组从考生试卷中**抽取样卷初步打分**，作为阅卷人后续评分的参考。

**评分阶段（多人评分制，实行十多年）：**
1. 一道题由 **2-3 人同时打分**；
2. 分差较小（一般在 **2 分以内**）→ 取平均值作为最终分数；
3. 分差较大（超2分）→ 流入命题人/专家组**复核裁定**（兜底机制）。

### 2. 核心观点

- 制度本质：一种工作制度——通过集中培训、多人评分、专家裁定，最大限度消除人的主观性和不稳定性，控制评分误差，满足择优选拔的核心目的。
- 申论分数**不是100%精准的**，有一定不稳定性；但误差被控制在约±2分内，足以把考生分出三六九等。
- 对制度的判断：从公平性（精确到小数点）看有理论优化空间，但综合技术、制度、效率看**实际无更优解，当下即最优解**。

### 3. 阅卷流程 → 反推作答策略

| 流程特点 | 反推的作答策略 |
|---|---|
| 人工阅卷、答案"和而不同" | 不必与参考答案一字不差，内涵一致即可；也别被机械的智能批改分数吓到/误导 |
| 样卷先行、阅卷人对照参考打分 | 答案结构、层次要贴近"标准样卷"的样子：分点清晰、小标题切割 |
| 酌情给分 = 阅卷人自由裁量 = 压分空间 | 把每个点写到"准确"而非"贴边"，直接消灭裁量空间——"写准了压分压不到你头上" |
| 多人评分、分差2分内取平均 | 两人都认可的点才是稳的点；答案的优点和缺陷都会被平均放大呈现 |
| 误差约±2分、专家裁定兜底 | **"50分的答案复核100次最多52分；80分的答案复核100次最低78分。"** 硬实力才是根本，实力硬了误差影响就小；不纠结小数点，想办法从63.5提到73.5 |

## 四、技巧课-材料阅读9：考场阅读次数及注意事项

### 1. 核心观点

- **只读一遍绝对不行**：只读一遍意味着必须边读边整理答案，而材料没完整读下来，宏观和中观理解就构建不起来，答案必然散乱、逻辑性差——这就掉进了**"无脑找点扫描式阅读"的陷阱**。"只读一遍材料，答案是不可能写得好的。"
- 最理想是**读三遍**；对大多数考生，**读两遍**是更适合考场的策略。因人而异：
  - 阅读快但理解慢（需反复读才能get重点）→ 适合三遍；
  - 阅读不快但一遍能分清层次主题 → 两遍足够。
  - 在**全真模拟**中摸索出适合自己的策略。
- 时间紧怎么办：**"不是减少次数，而是加快速度。"** 类比行测言语理解从50多分钟练到27-30分钟（提速30-40%）——申论同样可以提速，很多同学没意识到。提速靠两点：①课上讲的技巧（留意材料中的线索）；②阅读量增大带来的理解能力自然提升。

### 2. 操作方法：三遍阅读的分工

**第一遍：通读全文（构建宏观+中观）**
- 从头到尾通览，重点把握**中心主题、结构层次、段落大意**；
- 读完要知道："这篇材料从几个角度讲了一件什么事儿"→ 据此确定答案的**中观要点**：分几个大要点、每个大要点大概讲什么；
- 不需要把微观层次梳理清楚。金句：**"读材料一定是先整体再具体，先结构再内容。"** 材料中作用于中观层面的线索，主要在第一遍把握。

**第二遍：复核确认（最快，花不了几分钟）**
- 目的与第一遍相同（宏观中观），但功能是**确认**：层次划分有没有问题、要点归类有没有疏漏、从哪儿到哪儿是第一个大点/第二个大点；
- 为什么必须确认：只读一遍的层次划分不一定准，落笔后想改改不了；**中观层次的梳理决定整个作答的基调**——梳理好了后续作答非常顺利；
- 可省略的条件：阅读速度实在提不起来时，可省去第二遍，但代价是**第一遍必须读准**（层次划分不能出问题），否则微观梳理会很痛苦。

**第三遍：微观梳理 + 成文**
- 前两遍后作答框架已构建好，这一遍**边梳理微观要点、边写答案**，对框架做具体填充，答案随之呈现。

### 3. 注意事项

- 每遍目的不同、详略不同，不要三遍都用同一种读法；
- 关键是找到自己的节奏：有人答完还剩40分钟，有人大作文只写一半——在全真模拟中定策略，而不是考场上现试。
