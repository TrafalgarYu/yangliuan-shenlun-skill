# 08 杨柳岸申论体系核心思路梳理（总纲课）

> 来源：专题分享课，以2023年四川县乡卷"托育服务参评材料"题为载体，完整过一遍整个申论核心体系。
> 本篇是全体系的一次总串联：审题 → 三观构建 → 中观层次 → 逻辑成文。

---

## 一、核心观点

1. **意识 > 能力 > 技巧**。申论最重要的是解题的思维（意识），其次是能力，最后才是技巧。技巧有局限性，能力要靠思维激活。
2. **答案不是找出来的，是读出来的、梳理出来的**。这是全体系的总纲，一切反例（找点、找对策、标签式阅读）皆源于违背这一条。
3. **材料与题干互为"鸡蛋关系"**：鸡生蛋、蛋生鸡，互为配套。题干问的是啥，材料讲的一定就是啥——因此题干中抽象的问法（亮点、巧、变化）不需要你去定义和理解，只需读懂材料、抓住材料重点，材料的重点自然就是亮点。
4. **材料的逻辑就是答案的逻辑**。要点是客观的，逻辑也是客观的；踩点人人都会（要点重复度约80%），逻辑才是拉开分差的关键。
5. **中观层次是全体系最难点，也是分差所在**。公考是竞争性考试，别人做不到的你能做到，就能脱颖而出。
6. **一切问题的共同指向是材料没读懂**。抄还是概括、两份答案谁对、要不要背规范词——读懂材料后全部迎刃而解；读不懂则永远判断不了答案好坏，这与官方是否公布答案无关。
7. **当下考情已不容要素套路**。问法越来越创新（亮点/变化/巧在哪儿/规范化体现在哪儿），把灵活问法等同于某个常规要素，是十年前旧考情的解题方式，现在会"死得很惨"。

## 二、体系框架（文字层级图）

```
杨柳岸申论体系总框架
│
├─ 0. 总纲：意识 > 能力 > 技巧
│     └─ 答案不是找出来的，是读出来的、梳理出来的
│
├─ 1. 审题层
│     ├─ 审"非常规要求"（只此题有的要求，如"中心明确、亮点突出"）
│     ├─ 鸡蛋关系（题干↔材料互为配套 → 不必理解抽象问法）
│     ├─ 作答目的意识（参评材料=秀亮点 → 问题段是引子，不写入答案）
│     └─ 反例：要素式转化（亮点≠效果、≠对策；桥≠成效）
│
├─ 2. 阅读层：构建材料三观（立体解读，反对平面化）
│     ├─ 宏观：材料整体讲了一件什么事 → 体现在公文题答案开头
│     ├─ 中观：从哪几个角度切入（层次结构）→ 决定答案逻辑 ★难点核心
│     │     ├─ 特征：隐含在内，不直接给（至多以问题段/过渡句/总结排比暗示）
│     │     ├─ 来源：现场分析，非积累；靠阅读理解能力，思维上先要意识到它存在
│     │     └─ 本质：要点与要点之间的关系（总分 or 并列）= 大纲"把握给定资料各部分之间的关系"
│     └─ 微观：中观层次下的具体观点（具体做法）→ 直接对应答案要点
│           （宏观—中观—微观 = 树状图结构；中观通常转成答案大点或小标题，具体落点随任务变化）
│
├─ 3. 材料合理性意识（阅读层保障原则）
│     ├─ 作者一定有自己的叙述脉络，材料不是乱的
│     ├─ 打乱重组的解题手法几乎不存在（归类前先问：作者为何放这儿写）
│     └─ 反例：标签式阅读（标"问题/措施/成效"再归堆，破坏叙述脉络）
│
├─ 4. 成文层
│     ├─ 逻辑：总分/并列关系不能错位（三种典型错误见下）
│     ├─ 小标题规则：
│     │     ├─ 中观层：通常写成答案大点或小标题；托育参评材料这道题的小标题必须落在“亮点”上，不能泛化为所有题都写亮点
│     │     └─ 微观层：后面本身高度概括→不写；后面是展开→提取核心写
│     └─ 格式：公文题要有标题、成文空两格；参评材料也要写标题
│
└─ 5. 检验层
      └─ 材料读懂的标准：层次结构理清后，一切答案"如同白纸"，一眼看出问题在哪儿
```

**各环节衔接关系**：审题（鸡蛋关系）告诉你“抓材料重点”→ 三观解读中“宏观/微观通常较直接，中观靠分析”→ 中观层次体现要点关系（总分/并列）→ 形成答案逻辑。一般小题、公文题中，中观通常转成大点或小标题；单指定材料大作文中，宏观可转成中心论点、中观可转成分论点；全卷大作文还要分析材料与材料之间的关系。整条链路的底层支撑是“材料的逻辑就是答案的逻辑”。

## 三、原创术语及定义

| 术语 | 定义 |
|---|---|
| **鸡蛋关系** | 材料与题干互为鸡生蛋、蛋生鸡：命题人为了这道题写的这篇材料，材料也为这道题服务，二者互为配套。推论：题干问的是啥，材料讲的一定就是啥 |
| **材料三观** | 对材料的三个层面立体理解：宏观（整体讲什么事）、中观（从几个角度/层次切入）、微观（各层次下的具体观点） |
| **中观层次** | 隐含在材料内部的层次结构，即微观要点之间的共同指向与关系（总分或并列）；对应考试大纲"把握给定资料各部分之间的关系"，是答案逻辑与小标题的来源 |
| **材料的合理性意识** | 相信每篇材料都有作者自己的叙述脉络与逻辑，材料是合理的；解题只需找到并顺着它的逻辑梳理，而非打乱重组 |
| **标签式阅读** | 反例读法：边读边贴"问题/措施/成效"标签以便归类，完全放弃对材料的理解 |
| **找点找对策** | 反例解法：默认材料是平面的，从头找到尾摘取要点，再自行归类拼装 |
| **要素式转化** | 反例思路：把题干中灵活的问法（亮点、巧、变化）强行转化为常规要素（对策/效果）再去套找 |
| **对策邪教** | 对"一切题都找对策、都写动宾结构"这一思维惯性的贬称 |
| **平面化阅读** | 只有微观、没有中观层次的读法：看似讲了六件事，就写六个彼此独立的要点 |
| **非常规要求** | 只在这道题出现的要求（如"中心明确、亮点突出"），审题时重点审它 |
| **作答目的意识** | 从文种写作目的出发判断内容取舍（参评材料是"秀肌肉"，问题不写） |

## 四、老师强调的核心原则清单

1. 意识大于能力，大于技巧——先建立思维，能力才能发挥作用。
2. 亮点就是亮点，不把亮点等同于任何要素（对策/成效）；同理"桥"≠"成效"。
3. 不需要理解"亮点"是什么——读懂材料、抓住重点，重点自然就是亮点。
4. 材料是立体的不是平面的：微观要点之上必有中观层次（共同指向）。
5. 打乱重组的解题手法几乎没有——归类前先问"作者为什么放在这里写"。
6. 问题段常作过渡句/分割线（只有启下），是中观的线索，不是要写的内容。
7. 中观层次不是积累出来的，是现场分析出来的，每篇材料都不同。
8. 小标题必须是亮点（题干要求什么，小标题就是什么），"打造一支队伍"这类做法不是亮点。
9. 逻辑就是总分关系和并列关系，不能错位：总分写成并列=把微观当中观；中观写成宏观=把中观当宏观。
10. 抛弃公式化思维（动宾结构、是什么为什么怎么办）——当下考情会死得很惨。
11. 规范词是"害人之处"：背"推动高质量服务体系建设"这种词，看着高级，实际与材料重心不符。
12. 作答围绕写作目的整理：无效内容（如参评材料里的问题）不写，字数留给干货。
13. 具体点重复度80%，差距全在逻辑性——答案必须体现逻辑性才能突破分数瓶颈。
14. 不要打草稿，重点是在材料旁边标注。

## 六、三种典型错误（批改环节提炼）

| 错误 | 表现 | 病根 |
|---|---|---|
| 把微观当中观 | "加强政策支持"单独成大点，与"提供普惠托育服务"写成并列 | 没看出政策是为普惠服务保障的（总分写成并列） |
| 把中观当宏观 | 把"普惠托育"当整体宏观 | 普惠只是第一层的共同指向（中观），全篇宏观是"C县托育服务实践" |
| 要素式解题 | 写"培育队伍"当亮点 | 强调的不是队伍，是队伍里不同的人实现"医养教一体化"；且队伍是做法不是亮点 |

**中观重心判定的两个维度**：理解角度（材料反复强调什么——反复讲三类人群，是在论证"医养教一体化"）；技巧角度（小标题必须是亮点，"打造队伍"显然不是）。
