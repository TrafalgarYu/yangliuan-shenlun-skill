# 05 微观阅读与题型方法：概括题·分析题

> 来源：杨柳岸申论付费课技巧课（材料阅读6、7）+ 基础理论（归纳概括1、综合分析5）逐字稿
> 主题：微观层次梳理的三大线索 → 专项训练法 → 归纳概括题与综合分析题的作答体系

## 一、技巧课·材料阅读6：连词、高频词、段落划分

### （一）核心观点

- 微观层次的梳理 = 具体得分要点（采分点）的梳理。中观体现在答案的逻辑性与小标题上，微观体现在小标题后面的展开内容里（"一带二""一带三"中的"二"和"三"）。
- 三大微观线索中，连词和高频词起**提示性作用**，段落划分只有**参考价值**——用词刻意区分，因为段落"实在太灵活"，命题人有时一段一个点，有时把一大堆东西塞进一个段落，局限性非常强，不能完全作为判断依据。
- **强烈反对把技巧当真理**："很多材料的微观层次是没有线索的，是需要你靠理解能力硬读的。"技巧永远只是辅助，多练、提升阅读理解和分析判断能力"才是王道"。

### （二）操作方法

#### 1. 连词（老师惯称"衔接词"）

定位：过渡句连接的是大内容要点之间（不同角度/层面），作用于**中观**；连词连接的是**句子与句子、具体观点与具体观点之间**，作用于**微观**。连词"映射着作者的写作心理，是微观材料起承转合的具体体现"。

操作规则：

1. 读到连词先停顿，判断前后内容是什么关系（并列 / 解释说明 / 递进）。
2. **并列类连词（同时、不但……还……）**：前后各是一个要点，必须**分别精简和概括**，绝不能把连词之后的内容"精简没了"。典型错误：以为"邀请专家"是"开会"的一部分，漏掉一个点。
3. **解释类连词（及、即、也就是说）**：连词之后是对前文的解释说明，概括时抓住重点只写前面的内容，把解释部分删减掉，再删除修辞成分，让答案符合申论语言的简洁性要求。
4. 专业性强的内容（如"免申即享"这类不了解的概念），光靠阅读很难理清前后关系，更要靠连词判断"下文是对上文概念的解释"，避免整理答案时陷入无限纠结。

#### 2. 高频词

定义：反复出现的词汇（**两遍或两遍以上**），尤其是反复出现的**专业性名词**。

操作规则：

1. 发现某词在某部分反复出现 → "反复出现是强调"，该词很可能就是这部分内容的重点。
2. 看高频词出现的**位置**：出现在过渡句之后、总结句之中等关键位置，说明所在句子是中心句/概括句，这部分内容应**围绕该高频词来概括**。
3. 若某几个连续自然段反复提同一个词，而材料的上下文都没再出现 → 可判断这几段讲的是**同一件事**，且围绕这个高频词展开（对中观也有提示作用）。

#### 3. 段落划分

前提：由"材料合理性意识"推出——段落划分"肯定不是随心所欲的……是精心设计的，是有依据有考量的"。

操作规则：

1. **一段一个点**：部分材料按段落分层次，一个自然段对应一个微观要点（如"一心多点便民服务圈"，每段分别对应社区服务近、政务服务近、生活服务近、青年就业近）。
2. **按段做中观**：有的材料除首段总领交代外，"一个自然段讲一件事儿、对应一个层次"，可直接按段落划分理层次。
3. **反向校验**：如果分层时把同一个自然段拆得七零八落、拆进两个大要点 → 要反思是否理解错了。命题人把内容放进同一个自然段，要么说的是一件事，要么是从不同角度阐述同一件事，**一般不会把同一自然段的内容拆到两个大要点中**。

### （三）原创术语及定义

| 术语 | 定义（原话表述） |
|---|---|
| 衔接词 | 连词的杨柳岸式叫法，"我觉得好理解一些"，指句子与句子、具体观点与具体观点之间起连接作用的词 |
| 一带二 / 一带三 | 答案结构：一个小标题（"大哥"）统领两个或三个微观要点（"小弟"） |
| 材料合理性意识 | 命题人组织材料是精心设计的、有依据有考量的，不是随心所欲的 |
| 反复出现是强调 | 高频词的作用原理，判断段落重点的线索 |
| 提示性作用 vs 参考价值 | 连词、高频词够得上"线索"标准；段落划分"可能够不上线索的标准"，只是参考 |

### （四）真题/案例（压缩）

- **"简述N市做法及成效"题**："及"提示解释说明关系，只写前半"推出免申即享服务，增强企业获得感"，删掉解释部分与修辞成分。
- **公益项目运营材料**："真正的工作还在后面"统领三段；"同时"提示两个做法要点分别概括，"不但……还……"提示两个成效要点直接抄（原文本身简洁有概括性）；后面的展开内容是对成效的肯定性评价，不存在要点。
- **网格化党建材料**：三段反复提"网格化党建"、上下文均未出现 → 这几段讲的是党组织与网格化管理这一件事，中心句为"红色网格化管理"。

## 二、技巧课·材料阅读7：微观层次梳理专项训练（1）

### （一）训练方法（核心：三遍法）

1. **第一遍**：拿到案例先**自己梳理**微观层次，判断要点及要点间关系。
2. **第二遍**：听讲解，对照自己的梳理找差距。
3. **第三遍**：根据讲解**复盘**。
- 要求"每一遍都要真正入脑入心，不要像猪八戒吃人参果一样"；"学申论还是要沉得住气，耐得住寂寞"。
- 案例共六个，由易到难排列；无技巧可用时，靠阅读理解能力硬梳（案例一即如此）。

### （二）案例要点

**案例1（一带三结构，纯理解硬读）**：材料先抛问题"文化的生命在于用"，紧跟着回答——发展文化旅游让文化融入群众生活（整段核心观点=大哥）；后三个要点是小弟：生态文化旅游相融合（理念思路）、修建文化景观聚人气（吸引人来）、数字化赋能提升体验（让人玩好）。
- 金句：**"总分关系让答案有了层级，并列关系让答案有了次序，有层有次，答案便有了层次……这个就是申论的逻辑性。"**

**案例2（用段落划分+连词）**：梳理四要素"借鉴传统文化中的什么智慧、运用在什么领域、取得什么成效"。两段都是公共危机处理领域，但一段讲国内（团结→攻克疫情难关）、一段讲国际（奉献→推动构建人类命运共同体），整合为一带二答案。

**案例3（用过渡句+总结性排比+段落划分）**：
- 关键判断：场景交代一般出现在材料开头，若出现在第七段 → 这是**过渡段**，作用是引出下文养老话题。
- 第八段社区主任总结性观点中出现**递进词组**"满足需求和引领生活方式"——出现在具体内容中的总结性排比，**映射的是微观要点**（满足需求对应第十段、引领生活方式对应第九段）；区别于出现在中心句附近的总结性排比（映射全文、作用于中观）。
- 段落划分极清晰：第一段背景交代主题引入 → 第二段总结性观点 → 最后两段具体要点（与总结性观点呼应）。

### （三）方法论提示

- 技巧的组合使用：连词 + 段落划分；过渡句 + 总结性排比 + 段落划分。
- 微观层次梳理与中观层次梳理一样，**都以阅读理解为基础**；线索技巧只起辅助提示作用。

## 三、基础理论1：归纳概括题

### （一）核心观点

1. **"申论题型这个概念，它其实是教培的产物，它并不是申论的本质。"** 大纲中申论只讲考察什么能力、不讲题型（行测才有明确题型划分）；题型界限正越来越模糊（同一道题既可算概括题也可算综合分析题；对策题里也可能混入观点要素）。可以按题型入门，但不要把每种题型的作答思路"奉为唯一的真理"，要逐步**淡化题型、回归"问什么答什么，怎么要求怎么写"**。
2. "题审好了，材料读明白了，答案是水到渠成的。"学习重心永远放在**审题和阅读材料**上。
3. 归纳概括的本质：1000多字材料浓缩成200-300字，**考的是抓重点的能力**；它不仅是一种题型，**"其实也是整个申论作答的一个基础手法"**（除大作文外所有小题共用）。
4. 归纳概括题因只有两个层次、无复杂逻辑关系，**拉不开分差**。

### （二）题型识别

- 定义：题干中**很明确地**让你去概括某一个要素或多个要素。
- 最大特点：**要素的明确性**——题干清晰指出要概括什么要素（做法、成效、原因、巧妙之处、创新性问题等），"问的是很明确的"。
- 与综合分析题的区分：综合分析设问笼统委婉抽象（谈理解/谈看法/谈认识/做评价/对比分析），不告诉你概括什么要素。

### （三）完整作答流程（审题 → 找点 → 加工 → 书写的杨柳岸做法）

**第1步 审题——锁定要素**
- 从题干明确"要概括的要素是什么、有几种"（如"做法**及**成效"即两种要素）。这一步同时决定答案呈现形式（见第4步）。
- 借助**鸡蛋关系**建立预判：既然让你概括经验做法，材料讲的基本上就是经验做法；让你概括大桥的巧妙之处，整篇材料就在讲巧妙之处——题干与材料是"鸡生蛋"的对应关系。

**第2步 找点——不是"找"，而是"梳理"**
- "你不需要特意去材料里面找要点，你只要能够把材料梳理清楚，把三观构建起来，这个答案自然就出来了。"
- 分工明确：**中观层次的梳理决定答案分几条；微观层次的梳理决定每一条后面的展开内容（具体微观要点）。**
- 理念：**顺势而为**——"顺着命题人给你设置的这个思路、给你设置的这个路线去作答，千万不要拧巴。"

**第3步 加工——分条罗列**
- 核心思路：**分条罗列、踩点得分**。不存在复杂逻辑关系。
- 概括过程中的精简手法：删除解释说明部分、删除修辞成分，使表述符合申论语言的简洁性要求。

**第4步 书写——按要素数量定格式**
- **概括一个要素**：需要写**总括词**（总括词 + 分条展开的答案结构）。
- **概括多个要素**：不需要总括词，**直接分条罗列**即可。

### （四）配套刷题思路（基础理论5开篇的作业讲评）

- 题1（传统型）：分好层、读准每层重点（外观设计→整体拆除方案→废料处理→连接方式及效果），"答案基本就能写个八九不离十"。
- 题2（事前-事中-事后脉络型）：要点不按层分布而是"混成一团"，需**前后对比理清变化**才能得出答案；靠材料结尾的**总结性排比**线索提高梳理效率。
- 题3（多要素+案例型材料）：需通过对案例的解读提炼要点，"难度主要集中在审题上，题审清楚了就解决了一半"。

## 四、基础理论5：综合分析题

### （一）本质：为什么设问笼统

- 表层区分：设问笼统委婉抽象——谈谈理解、谈谈认识、做评价、谈谈看法、对比分析等。
- 深层原因在**"概括"与"分析"的词义区别**："知其然不重要，知其所以然才重要。"
  - **概括**：按照指定要求提炼出核心内容即可。
  - **分析**：从多个角度来阐述、解释指定对象。
  - 生活化例子："概括你中午吃了什么"→直接报菜名；"分析你中午吃了什么"→要讲菜系、好不好吃、有没有营养等多角度。
- 由此理解作答要求中的**"分析全面"**：不仅是要点上的全面，**同时也是角度上的全面**——对事物做全方位解读。答案包含的要素往往复杂且多元，所以题干没法把问题明确化，只能给笼统设问。
- 一句话：综合分析**"不像归纳概括那样指哪儿打哪儿，而是一种立体全面多角度的分析"**。

### （二）题型分类（按设问方式）

| 设问方式 | 举例表述 |
|---|---|
| 谈理解 | 请谈谈对这句话/这个概念的理解 |
| 谈认识 | 谈谈你对……的认识 |
| 做评价 | 对……做一个评价 |
| 谈看法 | 谈谈你的看法 |
| 对比分析 | 对……进行对比分析 |

（杨柳岸态度：从表征判断题型"本身没有太大的意义，说到底还是一个问什么答什么"。）

### （三）解题过程：先破后立

**破：坚决摒弃"是什么—为什么—怎么办"框架**

- 定性："这其实是一种**过时的、甚至可以讲是错误的作答思路**"，是"套路"。
- 论证一："每道题给的材料内容是不同，那用不同的原材料怎么可能做出同样的一道菜呢？"框架太理论化、理想化——有的材料只讲是什么和怎么办、不讲为什么，有的还讲别的。
- 论证二：强行套框架 = 无视材料逻辑、把材料在微观层面**打碎再归类重组**，与"顺势而为"完全相反，"属于是逆天而行"——过程痛苦、漏点、还拿不到分。
- 论证三：**"当下很多申论考生越学分越低的原因"**——纯小白时还知道理解材料，学了框架后"脑海里就只有框架"，反而得不到分。

**立：材料的逻辑就是答案的逻辑**

- "我们不需要固定的解题框架……**因为材料的逻辑就是答案的逻辑，材料的框架就是答案的框架。**"
- 操作：按材料的叙述逻辑把重点内容提取出来即可。例（撤柜台真题）：题干问"眼中的柜台"与"心中的柜台"，由鸡蛋关系可知材料讲的也是这个——材料先讲当下如何撤掉眼中的柜台、再讲未来如何撤掉心中的柜台；材料本身对二者的解释就是多维度的，顺着梳理自然全面立体。
- 常见疑问回应："要点散乱怎么办、要不要自己归类？"——**"说明你对材料的中观是没有构建起来的，所以在你眼里就只有散乱的微观要点"**；中观构建起来后，"材料本身是有叙述逻辑的，已经不需要你主观上再创造出一个逻辑出来了"。

### （四）答案呈现：先综合再分析（三层次结构）

**结构**（在概括题分条罗列的基础上多一层）：

1. **第一层：综合**（对应材料**宏观**）——答案开头先给一个**总结性、总领性的回答**，通常是对概念/划线句子下定义。
   - 有中心句可直接抄时：直接抄材料（如谈"种戏"理解的题，材料结尾的中心句就是对其的整体解释——因为题干让理解种戏、整篇材料讲的就是种戏，"材料的中心句儿它自然就是对种戏这件事儿的一个高度概括"，仍是鸡蛋关系）。
   - 没有现成中心句时：结合题干具体问题 + 对材料的宏观理解，**自己给划线句子下定义**（难度更大）。
2. **第二、三层：分析**（对应材料**中观和微观**）——结合材料正文罗列具体要点、全方位展开。如"种戏"题按材料逻辑从**唱戏人、听戏人、传承人**三方面人群梳理概括。
- 类比：技巧课每节"先给一句最核心经验（综合）→ 再具体展开（分析）"就是先综合再分析。

**逻辑分的得失机制**：要点还是那些要点，但若把微观要点拆进"为什么/怎么办"、按自己的思路打乱重组，"排列顺序已经破坏了原有的逻辑"，中观层面的三类人群就体现不出来——**"损失掉一部分的逻辑分数"**。这背后是**平面化理解与立体化理解的区分**：不能从微观要点中抽离、看不到其上隐含的中观脉络，就只能自己造逻辑。

### （五）与归纳概括题的系统对比

| 维度 | 归纳概括题 | 综合分析题 |
|---|---|---|
| 题干设问 | 明确指出概括什么要素 | 笼统委婉抽象（谈理解/看法/评价/对比） |
| 本质 | 按指定要求提炼核心内容，"指哪儿打哪儿" | 多角度立体阐述对象，"有什么写什么" |
| 答案层次 | 两层（无总括词则纯分条） | 三层（先综合再分析） |
| 逻辑要求 | 低，基本无复杂逻辑 | 高 |
| 分差作用 | 拉不开差距 | **能拉开分差**（与公文题并列，"概括题大家写得都还不错，对策题大家写得都很烂"的普遍考情下，综合分析和公文是拉开差距的关键） |
| 解题手法 | 带着明确目的梳理材料（基础手法） | 除第一句总结性回答外，梳理过程与概括题无大区别 |

### （六）学习建议

- 理论课与技巧课**结合着听**效果更好。
- 复杂内容先做作业再回听理论，"在练中学，在学中练"。
- "体会到了知识的时候，才是真正掌握了知识。"听课不要"听一个热闹"，要用研读材料的心态听课。
- 一对一批改的价值："申论这门学科你闷头学闷头听，效果确实是比较有限的……把单向的沟通变成双向的交流。"

## 五、贯穿全批的底层理念

1. **鸡蛋关系**：题干问什么，材料讲的就是什么——审题即预判材料。
2. **顺势而为（反对拧巴/逆天而行）**：材料逻辑=答案逻辑，任何打碎重组材料的框架都是反的。
3. **三观体系**：宏观（总体）→ 中观（框架脉络、决定分几条）→ 微观（采分点、决定每条展开），题型方法只是同一套阅读体系在不同设问下的投影。
4. **尊重材料三重奏**：不仅尊重材料的**客观内容、客观表述**，还要尊重材料的**客观逻辑**（分清主客）。
