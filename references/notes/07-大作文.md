# 07 大作文：立意与论述（杨柳岸·基础理论13-16）

> 总逻辑链：认知（写对>写好）→ 立意的标准化思路（老大/老一点五定观点）→ 试卷整体性意识（明线暗线）→ 抽象哲理类（化虚为实）→ 论述四要求与框架性思维。

---

## 一、大作文的基础认知及标准化思路（基础理论13）

### 核心观点

**主张：**
- 申论大作文"一定是在限定范围内去写作的"，命题人在题干和材料中给出限定条件，并非自由发挥；超出或偏离限定范围就跑题、偏题、少题。
- **"不求写好，但求写对"**——写对的重要性远大于写好。
- 大作文评分与小题完全不同，采取**定档打分**：阅卷人按整体水平先划档次（一/二/三/四类文，档差约10分）。**写对决定档次**（二类文以上还是三类文以下），**写好只决定档内分数**。文采飞扬但偏题，最多三类文偏上；平平无奇但不偏，最差保住二类文。
- 大作文考察的是**分析理解能力（材料处理能力），不是文字功底**——"能不能通过对题干和相关材料的分析理解来确定文章的立意，推导出文章的主要观点"是最核心考点。若考文字功底，考生背人民日报范文上场默写即可。
- 大作文与小题本质相同（都是材料处理能力），唯一区别：大作文更讲究对整套试卷的宏观把握，研究材料与材料、材料与题干的关系，不抠材料细节。
- **"申论大作文是整套试卷核心思想的集中体现。"**（老师强调"非常关键"）
- "申论大作文从分数角度来讲，是一个上限较低、下限极高的题型"：30分提到35分很难，15分提到30分只需解决思路问题。
- 申论从不考个人成长，全部站在社会、公共管理的角度命题（公考查职业匹配度）。
- 观点正确=不跑题偏题少题；**观点鲜明=分论点表述具体且直观**。命题人抽象化命题正是为了考理解分析能力，考生不能反把分论点写得模糊抽象去"考阅卷人"。

**反对：**
- 反对不解决认知就追求技巧、文笔、金句、背案例——"很多时候其实都是在做无用功"。
- 反对脱离题干和指定材料、跑到未用材料里找观点（主次颠倒）。

### 操作方法：标准化分析思路（完整流程）

四个分析依据，重要性与分析顺序自上而下：

| 排位 | 依据 | 定义与作用 |
|---|---|---|
| **老大** | 题干 | 以题干的话为核心做分析 |
| **老一点五** | 指定材料 | 题干明确点名"结合材料X"（注意是"指定"不是"给定"），与题干同等重要 |
| **老二** | 未用材料 | 小题未用、题干未提的材料，一定是为大作文准备的，起辅助与补充作用 |
| **老三** | 小题材料 | 前面小题用过的材料，本职为小题服务，对大作文有时有用有时没用 |

**五步流程：**
1. **分析题干**：拆出观点和角度。注意"双重限定"命题——既要求"结合对某句话的理解"、又"围绕主题"写文章，两处信息必须结合看。
2. **分析指定材料**：题干引文往往只给一半，要回到材料看全；从中补充新观点和新角度。
3. **整合**：把观点与角度融合成分论点（可直接写，也可润色成排比式；角度可不进分论点字面，放进论述方向即可）。
4. **辅助与补充**：用未用材料+小题材料加深对观点的理解，其中观点、事例可作论述素材。
5. **润色成文**。

优先级不用背——站在命题角度自然推出：题干明确要求的理所应当第一；未用材料"小题不用、大作文不提"（老师戏称"私生子"），必有大作文用途但分论点通常不直接源于它；小题材料有本职工作，垫底。

### 原创术语

- **写对 / 写好**：写对=立意准确清晰+结构语言符合基本要求；写好=文学性可读性（金句、巧妙标题分论点、充分论述）。
- **定档打分**：大作文先划档次、再在档内给分的评分模式。
- **双重限定的大作文**：题干同时含"对某句话的理解"与"围绕某主题"两层限定的命题方式。
- **老大 / 老一点五 / 老二 / 老三**：题干 / 指定材料 / 未用材料 / 小题材料的优先级排序。
- **未用材料**：整套试卷中小题题干完全没提到的材料，为大作文服务。
- **辅助与补充**：其他材料对题干和指定材料的作用——辅助=帮助理解，补充=提供可入文的观点与事例。

### 真题案例

2023江苏A卷"学习理解中华文明、古为今用"：题干拆出两个观点（学习理解中华文明、将中华文明古为今用）+一个角度（"绽放青春"=新时代青年角度）；指定材料补出第三观点"弘扬"及两个角度（用于中华民族现代文明建设、"超越国度"=向国际弘扬、讲好中国故事）→三观点两角度整合成文。反例辨析：学"和为贵"用于"做性格温和的人"（考个人）=错，用于"助力基层治理"=对。

## 二、试卷的整体性意识（基础理论14）

### 核心观点

**主张：**
- 有些试卷具有强整体性：**明线**（统一主题，较明确）与**暗线**（统一中心思想，抽象隐晦），贯穿全套或部分材料，都为大作文服务——试卷"行散而神不散"，"这个统一的神往往就呼应着大作文的立意"。
- "申论大作文是整套试卷核心思想的集中体现"可作为一种分析大作文的思维意识——**试卷的整体性意识**；文章的核心观点往往同时包含明线和暗线。
- 定位：这节课讲的是**道理**，上节课讲的才是**方法**。考场主要靠标准化思路，整体性意识是拓展和深化，起辅助作用（做23年国考三套卷用处大，24年国考作用相对小）。
- 国考的整体性非常强（"神一定不散"），省考可能散一些。
- 抓材料宏观的价值：即使对某些小题没用，对大作文也会产生作用。
- 复盘习惯："每道题做完，尝试用三言两语把这道题最核心的思路梳理清晰。"

**反对：**
- 学了这课就不分析题干、直接满卷找明线暗线定观点——"属于学的走火入魔了"。

### 操作方法（大作文主题如何从全卷提取）

**适用情形**：题干只给抽象道理、未给明确范围（如"长青之道，贵在自胜"）；或题干要求"结合全部给定资料"（山东、广东常见——此时**所有材料都是老一点五**，必须全部用上，否则少题）。

**三步：**
1. **判断命题形式**："结合全部资料"→全套材料同等重要、无老二老三；且说明这套卷一定"行散而神不散"，统一的神必与大作文有关。
2. **提取明线定方向**：题干没给主题时，梳理各篇长材料的宏观主题，找统一明线（即写作方向）。经验判断：题干只给一个虚的道理，前面材料中必有一个统一主题，否则这道题就没法做了。
3. **处理"四长一短"结构**：短材料（篇幅短、讲精神品质而非实践，与前文明显不同）极可能是对前面长材料的总结呼应 → 把长材料的具体实践与短材料的精神品质**结合着看**：**精神品质=分论点**（对抽象道理的细化），**具体实践=论据**（放进对应分论点后），从而落实"结合全部给定资料"的要求。

### 原创术语

- **明线 / 暗线**：整套（或部分）材料的统一主题（明确）/ 统一中心思想（抽象隐晦）。
- **试卷的整体性意识**：以"大作文是整套试卷核心思想的集中体现"来看待和分析大作文的思维意识。
- **行散而神不散**：各篇材料表面主题各异，实则共享统一的主题或中心思想。

### 真题案例

"长青之道，贵在自胜"（结合全部资料）：前四篇长材料（小岗村农村土地改革、社区基金与社区治理体制改革、万华集团国企改革、共富公司"三变"改革）统一明线=**改革**；材料五为短材料、讲精神品质 → 中心论点"通过改革创新，不断打开事业发展的新天地"，材料五各精神=分论点、前四篇实践=论据。另例：2021国考地市四篇材料皆讲"社会治理"（明线），每篇结尾均呼应大作文"遵循规律"（暗线），中心论点"社会治理要遵循规律"。

## 三、抽象哲理类大作文·热门考点（基础理论15）

### 核心观点

**主张：**
- 近年热门命题类型：有形与无形、流动与新生、力与理、精度温度力度、有和无、长青之道贵在自胜——题干论题具有哲学意味、十分抽象。
- 与范围明确的命题（如23江苏A）正相反：这类题的主题、分论点等限定条件**模糊且抽象**，范围要靠材料分析才得出。
- 最核心的解题方向是**化虚为实**："把具有一定哲学意味的、比较抽象的大道理，转化为对社会发展的某个领域具有实际价值的明确的观点"——即"把论文写在大地上"。不能就着道理讲道理，否则观点不鲜明。
- 化虚为实**不需要课下准备和积累**，是围绕主题、结合材料分析推导出来的（若"合作共赢"出成题，整套试卷必有统一主题，各篇材料分别给出具体角度）。
- 定位：化虚为实是**方向**，方法仍是标准化分析思路。
- 直觉判断源于刷题经验："共情能力其实也是理解能力的一种"——揣摩命题意图；但直觉可能对可能错，关键还在分析判断。
- "有效竞争"观：公考表面竞争大（千里挑一），但"真正的有效竞争力在所有考生里能够占到五六成就不错了"。

**反对：**
- 反对"辩证性大作文"套路（分论点一讲A、分论点二讲B、分论点三讲A与B的关系）："材料都没分析呢，他先把思路给确定下来了……恭喜你都会抢答了。""在分析材料之前就能够确定写作框架，说明这是一种脱离了材料的东西，这种东西我们统一叫做模板。"
- "好用的东西，它不一定是正确的东西"——很多方法是教培机构投你所好的产物，要有鉴别能力。
- 反对"太聪明的人学不好申论"式营销——"给学生先降智再洗脑的一种营销行为"。
- 反对万能套路："出现两个词一定是A带来B、B带来A"——至少对23国考这道题不对。
- 反对因不会论述而更改观点："你就算后面硬写，你也比跑题强。"
- "要按照命题人的思路去作答，而不是按照自己的性子去作答。"

### 操作方法（破解步骤）

通用判断链：看题干给了**几个抽象概念、结合几篇材料** → 推断概念与材料的对应关系（一对一？还是每篇一个角度？）→ 读懂材料宏观（→中心论点）与中观（→分论点）→ 化虚为实 → 润色成文。

**四种情形（由易到难）：**
1. **单材料+概念明示型**（四川"精度温度力度"）：题干只提材料四、无老二老三 → 只看材料四：其宏观（数字化赋能基层社会治理）=中心论点；其中观分别对应三个度=分论点，且材料原文直接给出（社区治理的精度、公共服务的温度、多元共治的力度）。
2. **单材料+概念需解读型**（2024国考行政执法）：材料未明说三个"力"各指什么，需自己解读材料中观层次——思路完全一致，难度更大。
3. **双概念+多篇材料型**（事业单位"政务服务的有和无"）：题干给一对抽象概念+明确主题，结合三篇长材料 → 经验直觉：两个概念、三篇材料，不是每篇对应一个概念，而是**每篇材料换一个角度讲这对概念** → 每篇材料=一个分论点，在各篇中分别分析"有""无"的具体内涵（居民服务的温度与效率之平衡、对企业的管理与支持之平衡、数字化改革与群众生活便利之关系）。
4. **题干句延伸型**（2023国考副省"流动与新生"）：无指定材料，**题干中的三句话等同老一点五**（短篇幅指定材料从某种程度上可看作对题干的一种延伸），全套小题材料都是老三 → 先读懂三句话：第一句（大河奔流）是抽象总起、代指整个话题；后两句较具体——桥梁路网=资源要素（人流物流信息流）流通促进经济，产业转型升级=焕发活力释放动能促经济 → 两个核心观点：**资源要素流通促进经济发展、产业转型升级促进经济**（"所有讲到活力，它一定就是经济"）；第三个分论点可结合材料逻辑补充（资源充分交融为产业转型打下基础——所有材料都是先流动、后新生）；最后用整套试卷的共同指向验证（国考整体性强，全部材料共同指向这两个观点）。
5. **收尾**：分析结果→（有角度则整合）→润色成文（如"资源要素的流通是经济发展的重要引擎；产业转型升级是市场活力的催化剂"）。

### 原创术语

- **抽象哲理类大作文**：论题具有哲学意味、十分抽象的命题类型（与范围明确型相对）。
- **化虚为实**：把抽象道理转化为对社会发展具有实际价值的明确观点（是方向，不是方法）。
- **辩证性大作文（反面术语）**：市面对"有和无"类命题的错误归类及套路化处理方式。
- **有效竞争**：考生中真正构成竞争的群体（约占五六成）。

### 真题案例

2023国考副省"流动与新生"：题干三句话前抽象后具体，"中间来一刀"——流动特指资源要素流动，新生特指产业转型升级，共同结果是促进经济发展；大量考生套辩证模板写"流动是新生的基础/新生是流动的目标/把握辩证关系"——脱离材料、观点不鲜明，跑题。同年国考地市卷、执法卷思路相同，只是把题干三句话换成了一篇两段的短材料。

## 四、论述的基本要求及框架性思维（基础理论16）

### 核心观点

**主张：**
- 读人民日报等官方文章**对立意没有价值**（立意是分析出来的，不是课下积累出来的），价值在于**学文风**。
- 申论文风：**严谨准确、简练朴实、清新中带一点庄重**，金句只在关键处点睛；主要内容一定以准确严谨的平实叙述为主。
- **论述充分 = 内容构成丰富 + 角度多变**；论述 = **论证 + 论据**，两者都要有，且**论证占比最好大于论据**（300字里200字举例子=自己的观点太少）。论据不只有举例，还可引用领导观点。
- **结构清晰 = 整体布局 + 微观框架**：整篇文章"131"结构（开头-分论点-结尾）；每个论述段内部也要有合理框架（如"正反+总结"），让人读得通、读得顺、能明显感受叙述逻辑。
- 结构清晰与论述充分相辅相成。
- 框架性思维解决凑字数：论述框架打好后，"300字的大任务就被细化成了三个100字的小任务，甚至四个75字的小任务"。
- 论述是分论点的解释说明，**必须围绕分论点展开**；论点与论述"各说各的"是常见低级错误。
- "解决掉认知方面的问题，很多实操方面的问题也会迎刃而解。"

**反对：**
- 反对浮夸文风（"晨曦破晓""春夏秋冬四种花"通篇修饰——"不知道的以为写修仙小说呢"）；反对金句堆砌——**"你如果浑身都是眼睛，那不是龙，那就是蜘蛛。"**
- 反对小学生流水账。
- 反对论述与论点不匹配：反例段落分论点写"发展传统文化"，论述却讲如何运用、如何宣传推广，唯一总结还放在段中间——"内容上没有重心，有点不知所云"。

### 论述的四个基本要求

1. **语言流畅准确**：模仿官方文章文风——准确严谨简练朴实为主、恰当金句点睛，避免浮夸与流水账两个极端。
2. **结构清晰**：宏观上"131"布局（有头有尾有分论点）；微观上每个论述段有清晰框架（如正反+总结），正面讲完再讲反面，不来回跳。
3. **论述充分**：
   - 内容构成丰富：道理论证+举例说明（+酌情总结建议），论证>论据；论据可举例、可引用领导观点。
   - 角度多变：正反、整体↔个体、古今、中外、递进、不同主体等；举两个例子必须构成对比（正反/古今/中外），同角度堆例子=凑字数。
4. **论述与论点匹配**：论述围绕分论点展开、解释说明分论点。自检法——**写完把分论点遮住，看能否像做申论一样从论述部分把分论点反推出来**，能反推=匹配。

### 框架性思维与模板的区别

- **模板**：在分析材料之前就能确定写作框架——先入主、脱离材料的固定套路（如"辩证类"三段式），考场好写但难拿分，因为背离了材料；"越追求在考场上省事儿，越容易出问题，因为材料千变万化"。
- **框架性思维**：框架产生在材料分析**之后**——先按标准化思路从题干和材料推导观点，再为观点搭论述框架（论证+论据+多角度布局）；框架是内容的组织方式，内容随材料千变万化，框架章法不变。
- 本质区别：**框架服务于分析结果，模板替代了分析过程**。用好框架思维可以"有1000种策略"随机应变地满足四个基本要求，同时把300字大任务拆成小任务，既写得好又好写。

### 正反案例

- 反例：分论点"发展传统文化"，论述通篇讲运用、宣传推广，未讲如何发展、发展的结果与意义，总结置于段中——观点不鲜明、论述不充分、结构不清晰。
- 正例：分论点"古为今用，让新时代青年成为优秀传统文化的践行者"——道理论证（解释古为今用、融入当代内涵）→举例（六尺巷故事启发大山村党员干部化解土地纠纷）→总结收尾、首尾呼应：中心明确、结构清晰、论证论据兼备。"能达到这样的标准就完全够用了。"

## 附：四课逻辑串联

认知层：定档打分 → 写对>写好 → 立意靠分析不靠积累。
立意层：标准化思路（老大+老一点五定观点，老二老三辅助补充）→ 整体性意识（明线暗线，应对"结合全部资料"与无范围命题）→ 抽象哲理类（化虚为实：概念个数×材料篇数 → 判断对应关系 → 材料宏观=中心论点、中观=分论点）。
论述层：四个基本要求（语言、结构、充分、匹配）+ 框架性思维（先分析后搭框架，反对先入为主的模板）。
