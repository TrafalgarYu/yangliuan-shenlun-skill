# 03 审题（技巧课 10-12）

> 杨柳岸技巧课·审题三讲。技巧课以**作答流程**为导向（审题→读材料→整理答案），区别于以题型为导向的理论课。三句核心总结，一句一讲。

---

## 第一节 审题的核心要义：问什么答什么，怎么问怎么答

### 核心观点
- **审题核心要义一句话：问什么，答什么；怎么问，怎么答。** 听起来像废话，但正因为太简单，考生反而放松警惕、答非所问翻车。
- 答非所问的后果：最少丢一半以上的分，且**考生自己往往不自知**——"分丢得神不知鬼不觉"。方向错了，逻辑清晰、语言准确都失去意义（"人家问1+1等于几，你说我在家排行老二"）。
- **反对**市面上主流的"审范围、审问题、审场景、审身份"式要素审题法：过于理论化，考场上没人真的这么操作。
- **反对**机构把概括题细分为"概括做法/问题/成效/意义/变化"的套路：导致考生遇到创新题就往常见要素上靠，用常见要素去解释不常见的概念，是答非所问的重要根源。
- 题目越出越新（申论、面试、行测皆然），公式化、流水线式的解题方法已经不适用。"明朝的剑斩不了清朝的官"，回归问题本身才是亘古不变的道理。
- 刷题越丰富的考生越能感受审题的分量（"老司机开车越开越慢"）；小白最容易吃大亏而不自知。

### 操作方法
1. **把题干拆成两部分**：前半段通常只是客观叙述（介绍材料讲了什么），**后半段才真正提出问题**——作答对象以后半段为准。
2. **审题要同时把握两个维度**：
   - 内容方向：概括/分析的对象到底是什么；
   - 结构形式：如"用一段话概括"——不能列一二三四，必须把要点串成一整段。
3. 遇到指代模糊的提问（如"请**对此**进行归纳概括"），"此"指代的是题干前半段的**全部要素**，不是其中某一个词。逐一拆出要素（如：哪些地方＋什么智慧＋什么领域＋什么成效，四要素缺一不可）。
4. 遇到生僻问法（如"桥在哪儿"），不要往"对策/意义/问题"等要素上套，**直接回答所问的那个概念本身**。

### 真题/案例
- 江苏概括"做法产生的积极效应"：前半段是客观叙述，只需概括积极效应，且须"用一段话"呈现。
- 江苏次年"借鉴传统文化智慧赋能治理……请对此归纳概括"：大量考生因惯性思维只概括"显著成效"，漏掉其余要素，**直接少了四分之三的要点**——命题人用似曾相识的题干设陷阱。
- "玉林湖大桥桥在哪儿"：错误示范是把"巧"硬套成意义/对策等要素。

## 第二节 科学的解题思维：把握题干与材料的"鸡蛋"关系

### 核心观点
- **"鸡蛋"关系（原创术语，完整表述）**：先有鸡还是先有蛋？申论命题同理——材料大多可溯源（如23国考GEP题源自浙江丽水报道），可说先有材料；但材料又经过增删修改以契合题干，且命题必先确定考察范围再找材料，又可说先有题目。结论：**申论材料决定着申论题干，申论题干也指导着申论材料；二者像榫卯结构，高度契合、相互配套、互为鸡蛋**（蛋可生鸡，鸡可下蛋，反复生鸡下蛋，最终有了这道题）。
- 金句："**有时候你会感觉命题人就是为了这碟醋才包的这顿饺子**"（材料是饺子，题干是醋）——一旦有这种体会，说明答题方向没偏，正走在命题人设置好的既定路线上。
- **"答案是读出来的，不是找出来的"的完整逻辑**：
  - 因为题干与材料互为鸡蛋、高度配套，**题干所问的一定就是材料主要讲的内容**；
  - 所以对材料阅读的结果**无需加工、无需筛选，它本身就是答案**（如读玉林湖大桥材料，读出来的就是"巧在哪儿"）；
  - 只要审对题、读懂材料，答案就是**水到渠成、梳理出来**的结果。做菜比喻：考官让你做番茄炒蛋，材料给的原料肯定就是番茄和鸡蛋，你只需加工，无需另找。
- **"黄金矿工"式思维（原创术语，批判对象）及其错误**：审完题先把问法（如"巧"）自行定义清楚（精湛技艺/精细做工/灵活身手），再拿着自以为的理解去材料里**筛选、找**符合的内容——像玩黄金矿工一样在通篇材料里捞。错误根源在于**把题干和材料割裂开来**，没把握住鸡蛋关系：效率低、容易漏点；在公文题中最泛滥——先背好框架（如调研提纲先定死"目的/地点/对象/方式/内容"），再往框架里拼凑找来的信息，于是不断纠结"材料没给调研地点我要不要编""材料讲了我框架里没有的东西要不要写"。正确做法是**顺势而为，顺着材料脉络整理答案**。
- 为什么先审题再读材料：审题能获得**预思路**，带着目的性阅读，提高解题效率。审不出预思路也没关系——先把题干放一边直接读材料，但读的过程中必须**反复回顾题干、边读边审题**。
- 审题与读材料互相成就：审题帮助理解材料；对材料有了理解之后，回头看题干的问题也会随之清晰（如"巧在哪儿"）。

### 操作方法
1. 读材料前审题：分析题干关键词获取预思路（如"变化"＝实施前状态 vs 实施后状态的**前后对比**，读材料时就重点抓前后状态对比）。
2. 审不出预思路不纠结，直接读材料。
3. 读材料全程反复回看题干，尝试把握材料谋篇布局与题干的对应（如材料按"事前—事中—事后"脉络写，正因考的是"变化"＝事前事后对比）。
4. 用材料的叙述脉络（如画家采风日记＝按参观顺序的所见所闻）作为阅读线索，顺脉络梳理要点。
5. 注意语言的准确性要贴合材料强调的角度：画家对大桥的第一印象是**视觉冲击**，所以要写"外观设计巧/造型设计巧"，不能笼统写"设计巧"（设计还含施工工程、功能寿命等范畴）。

### 真题/案例
- 概括枫林村的变化：预思路＝"村寨银行"实施前后的对比；材料恰按事前事中事后布局，题干与材料高度契合。
- 玉林湖大桥"巧在哪儿"：整篇材料（画家采风日记）以参观流程为线索从不同角度讲桥的巧妙，读出来的内容本身就是答案。

## 第三节 审题的关键技巧：注意藏在题干中的线索

### 核心观点
- 命题像密室逃脱：命题人**怕你不会写**，经常在题干中埋藏线索与暗示，跟着引导走，解密方向就不会错。
- **命题人从不啰嗦**：公考命题极严谨，题干经过反复考量、修改、审核，**没有一个字是多余的**。看似与问题无关的"多余信息"（带引号）绝不会是废话——若无用早在审核中被精简掉了，它一定是线索。
- 两大类线索清单：
  1. **题干中的"多余信息"**——出现在问题的前半段、看似与提问无关的铺垫句；
  2. **题干中的"非常规要求"**——出现在作答要求部分。
- **常规要求 vs 非常规要求（术语定义）**：
  - 常规要求＝说与不说都必须满足的要求：全面、准确、有条理、紧扣资料；综合分析的"分析深刻/全面"；对策题的"针对性/可行性"。表述会变形（如"所提建议切实可行""对策与问题一一对应"），换汤不换药。
  - 非常规要求＝命题人精心设计的要求，起线索作用，具有**很强的提示性意味**。
- 线索的双重作用：既是**作答思路的暗示**，也是**材料结构的映射**——"命题人把路给你铺在这儿了，就看你走与不走。"
- 从一道批改案例得出的判断：当下考生**要点齐全上差别不大，差距主要在语言和逻辑**。
- 思维层面技巧让人不出错、不走歪路；技术层面技巧帮人做快做好，二者同等重要。"当你能把虚的变成实的，说明你真正学会了"（教育的滞后性，理论要学两遍）。

### 操作方法
1. **捕捉"多余信息"并做预判**：看到提问前多出来的一句铺垫，立即用它预测答案结构。如"生态系统具有直接、间接、潜在三种价值属性"＋"A市如何利用GEP实现生态产品价值"→预判答案应按三种价值属性组织；读材料验证：三种实现方式恰好一一对应（生态旅游项目＝直接价值，生态助力产业＝间接价值，碳汇交易＝潜在价值）。
2. **批改要点的逻辑判断**：要点是否算"实现价值"，看它是不是中间流程——"催生金融产品解决资金需求"只是流程/环节（好比"你爸给你的20万开店钱"不是你通过主业实现的价值），应并入对应的实现方式中，不能单列。典型病症＝**要点齐全但逻辑出了问题**。
3. **逐条审作答要求，识别非常规要求**：
   - 如"由意义、问题、措施三方面内容构成"→直接提示公文主要内容板块；
   - 如"意义全面、问题精准、措施可行"→提示三方面内容各自的写法重心；
   - 如"层次分明"≠"逻辑清晰"：命题人从不啰嗦，两个词若同义必被精简掉其一。"层次分明"是对结构上的补充提示——要求把各方面内容**分出层次、不可混答**。
4. **用非常规要求反推材料结构**：题干之所以这么要求，说明材料本身就是这么写的（材料必已分好意义/问题/对策三层）。若题干要求与材料矛盾（如材料中对策与问题并非一一对应），命题人就不会出"一一对应"式要求——这正是鸡蛋关系的运用：**改了题干，材料就得跟着变**。
5. 拿不准作答结构时，用非常规要求在多种结构方案中做排除（如"建议书"按板块分层写，而非"问题—对策一一对应"写）。

### 真题/案例
- GEP题（23国考）：题干"多余信息"给出三种价值属性，答案应按三属性组织；市面常见答案分四条且把"催生金融产品"单列——逻辑错误，应将其并入旅游项目一条。
- 江苏建议书（23年）："由意义、问题、措施三方面构成"＋"意义全面、问题精准、措施可行"＋"层次分明"——三条非常规要求共同锁定内容板块与分层结构；有学员套用对策题"一一对应"结构，写到一半发现对策与问题对不上，卡死。
- 文化建设建议书反面案例：黄金矿工式贴标签阅读（逐句标注"这是问题/意义/对策"再合并同类项）→答案散乱不成文，甚至把材料铺垫部分的生态治理内容也写进文化建设建议，答非所问。根源＝忽略对材料的理解，只关心句子属于哪个要素。
